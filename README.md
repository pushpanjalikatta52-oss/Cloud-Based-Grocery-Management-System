# Cloud-Based Grocery Management System

The **Cloud-Based Grocery Management System** is a web-based application designed to simplify grocery inventory management. It allows users to add, view, search, and delete grocery products while maintaining important information such as product name, category, price, and stock quantity. The project uses **HTML, CSS, and JavaScript** for the frontend and **Node.js with Express.js** for the backend. It provides a simple, responsive, and user-friendly interface for managing grocery inventory efficiently.

## Features

* Add new grocery products
* View available products
* Search products by name or category
* Manage stock quantity
* Calculate total inventory value
* Delete products
* Responsive design
* Backend REST API
* JSON-based data storage

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Node.js
* Express.js
* JSON
